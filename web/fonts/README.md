# Tipografía Inter

Fuente variable original, sin modificaciones, obtenida del repositorio oficial
de Google Fonts el 30 de octubre de 2026:

- Fuente: https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf
- Licencia: https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
- Autores: The Inter Project Authors. Licencia SIL Open Font License 1.1,
  conservada íntegramente en `OFL.txt`.

La aplicación local importa la fuente mediante `@font-face`. La construcción
del HTML portátil incrusta el mismo TTF como `data:` y adjunta la licencia,
de modo que no depende de conexiones a Google Fonts durante su uso.
